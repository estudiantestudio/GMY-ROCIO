# Focus Forest · Rocío 🌲

Aplicación personal para organizar:

- entrenamientos;
- hidratación;
- suplementos;
- alimentación saludable;
- metas;
- estadísticas;
- bosque virtual de recompensas.

## Características

- Diseño adaptable a celular y computador.
- Nombre personalizado para Rocío.
- Datos guardados mediante localStorage.
- PWA instalable.
- Funcionamiento básico sin conexión.
- Calendario deportivo.
- Control de agua.
- Registro de suplementos.
- Registro de comidas.
- Metas diarias.
- Estadísticas semanales.
- Modo claro y oscuro.
- Exportación de datos.
- Bosque virtual.

## Publicación

La aplicación puede publicarse gratuitamente mediante GitHub Pages.

## Importante

La aplicación no entrega recomendaciones médicas ni prescribe dosis de
suplementos. Las dosis deben basarse en las indicaciones de la etiqueta
del producto o de un profesional de salud.
